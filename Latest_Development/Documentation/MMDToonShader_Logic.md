# MMD Toon Shader (HLSL) 核心渲染管线深度解析

本文档深度解析了本项目中使用的核心 HLSL 着色器（`MMDToonShader_SM5_SingleFunc.hlsl`，非 AI 驱动版本）的底层数学逻辑与工程实现细节。本着色器舍弃了虚幻引擎内置的光照模型，在纯代码层面重构了一套极致可控的二次元渲染基座。

---

## 1. 架构总览与技术路线抉择

本 Shader 专为 Unreal Engine 5 的 **Unlit（无光照）** 材质模型设计，所有的光照计算全部在单段 HLSL 代码中完成，最终直接输出到 `Emissive Color`。

### 1.1 为什么抛弃 PBR 物理渲染？
二次元插画的美感来源于“反物理”的主观简化与夸张。基于物理的渲染（PBR）追求能量守恒和真实微面元反射（BRDF），这会导致暗部出现浑浊的真实阴影，高光区域呈现复杂的物理散射。为了还原纯粹的二次元风格，我们必须彻底抛弃 PBR 规则的束缚，接管每一个像素的明暗计算权。

### 1.2 为什么必须使用 Custom Node 与 TextureObject？
为了实现自适应的 Matcap（材质捕获）映射，我们必须在代码内部基于相机向量实时重新计算 UV 坐标。如果使用常规的纹理采样节点传入颜色，UV 已经被引擎固化。通过将贴图以 `TextureObject` 形式传入 Custom Node，我们在 HLSL 内部获得了底层的 `Texture2D.Sample()` 调用权限，实现了极致的 UV 控制力。

## 2. 基础底色与数学级色调修正 (Tinting)

为了在同一个材质实例下实现丰富的换色功能（例如角色皮肤冷暖微调），Shader 在获取 Base Color 后，引入了一套数学级别的色调混合系统。

**底层逻辑拆解：**
我们没有使用简单的乘法（那会导致画面死黑），而是实现了三种经典的图像混合算法（`TintMode`）：

*   **Mode 0 (Overlay 叠加)**：这是最核心的换色魔法。
    *   **数学原理**：`Base < 0.5 ? (2.0 * Base * Tint) : (1.0 - 2.0 * (1.0 - Base) * (1.0 - Tint))`
    *   **为什么重要**：它是一个极其聪明的算法。对于底图中的暗部区域（如衣物褶皱），它执行正片叠底加深颜色；对于亮部区域，它执行滤色提亮。这保证了在进行剧烈的色调偏转时，贴图原有的手绘明暗细节被完美保留，绝不丢失体积感。
*   **Mode 1 (Multiply 正片叠底)**：纯粹的 `Base * Tint`，用于大面积压暗环境。
*   **Mode 2 (Soft-Light 柔光)**：相比 Overlay 更平缓的非线性映射，极其适合进行亚洲人皮肤的暖色温微调，不会产生刺眼的色块。

## 3. 三层平滑卡通阴影 (Three-Layer Toon Shading)

这是整个 Shader 塑造立体感的灵魂。传统的 Cel-shading 只有非黑即白的 0/1 切断，而本项目设计了参数化的三段式阴影色带。

### 3.1 核心驱动：光照衰减值映射
首先计算经典的 Lambert 光照 `NdotL = dot(Normal, LightDir)`，并将其从 `[-1, 1]` 线性映射到 `[0, 1]` 的 `LightAtten`，作为判定受光程度的唯一标尺。

### 3.2 阈值系统与防崩溃设计
*   **T1 (ShadowThreshold)**：最深阴影（Shadow1）的物理边界。
*   **T3 (ShadowEnd)**：绝对亮区的起始点。
*   **MidSplit**：决定中间过渡带（Shadow2）宽度的插值系数。
**数学防御**：在代码层面强制插入 `T3 = max(T1, ShadowEnd)`。如果外部输入错误导致亮区起点低于暗区，系统在底层会自动将色带宽度塌缩为 0，防止出现负权重导致的渲染黑洞 BUG。

### 3.3 抗锯齿与平滑过渡 (Smoothstep)
放弃生硬的 `if` 逻辑，采用 HLSL 的内置硬件级插值指令：
`smoothstep(Threshold - EdgeHalfWidth, Threshold + EdgeHalfWidth, LightAtten)`
**为什么重要？** 这在数学上产生了一条两端平滑、中间陡峭的 S 型曲线（Hermite 插值）。它让阴影边缘带有细腻的羽化效果，不仅消除了模型低多边形带来的锯齿（Aliasing），更模拟了高质量赛璐璐动画中笔刷晕染的质感。

## 4. 彻底解决痛点：自适应防死锁球面映射 (Matcap Mapping)

Matcap （材质捕获）常用于表现头发天使环（Angel Ring）或金属。传统的做法是提取“视点空间”下法线的 X 和 Y 分量作为 UV 坐标。

**致命痛点：万向节死锁 (Gimbal Lock)**
当玩家摄像机移动到正对角色头顶（鸟瞰）或脚底时，相机的 `Forward` 向量平行于世界的 `Z` 轴。此时用于求取相机 `Right` 和 `Up` 向量的叉乘算法（Cross Product）会退化为零向量。这导致 UV 坐标瞬间崩溃为 (0,0)，画面上的高光会发生极具破坏性的闪烁和跳变。

**创新解法：无缝双参考系插值算法 (Singularity Fix)**
本 Shader 实现了一套极高学术水准的纠错机制：
1.  **构建双重正交基**：除了基于世界 Z 轴的主参考系（Ref A），额外构建了一组基于世界 Y 轴的备用参考系（Ref B）。
2.  **点乘探测**：实时计算相机的对齐程度（`AlignA = abs(dot(CamDir, float3(0,0,1)))`）。
3.  **C1 连续的平滑过渡**：当检测到 `AlignA` 逼近死锁区域（如大于 0.85）时，利用 `smoothstep` 将基向量的计算权极度平滑地移交给备用参考系 B。
**为什么重要？** 这一算法在三维数学上彻底抹除了极点奇点，保证了映射函数在整个球体表面都是 **C1 连续**（函数连续且导数连续）的。不论玩家镜头怎样作妖般地狂甩，天使环高光都能如丝般顺滑。

---

## 5. 参数化截断高光 (Truncated Blinn-Phong Specular)

有别于 PBR 根据微面元分布计算出的漫反射高光，这里的 Specular 是完全“主观操控”的经典 Blinn-Phong：

*   **计算内核**：基于半角向量 $H$ 与法线 $N$ 的点乘 $N \cdot H$，结合指数 $Power$ 实现高频锐化。
*   **截断 Mask 技术**：为了防止在不合逻辑的背光面出现“暗部反光”（这会彻底摧毁二次元的扁平感），代码基于 `NdotL` 额外生成了一个 `smoothstep` Mask。强制将未受光区域的高光权重归零，实现了物理与手绘审美的完美融合。

---

## 6. 总结

`MMDToonShader_SM5_SingleFunc.hlsl` 是一套高度工业化、极度轻量级的渲染基座。它摒弃了冗杂的物理写实算法，通过引入双参考系 Matcap 纠错、平滑 S 曲线分层、以及严密的数学混合逻辑，在极低的性能开销下，赋予了美术人员对于画面“每一丝阴影、每一抹高光”的绝对统治力。
