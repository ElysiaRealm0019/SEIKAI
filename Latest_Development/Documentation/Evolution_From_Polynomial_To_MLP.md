# 技术演进复盘：从多项式拟合到 MLP 神经网络的降维跨越

在构建“基于光照角度动态调整 Shader 参数”的系统初期，我们并未直接采用神经网络这一前沿工具。相反，基于传统图形学的工程惯性，我们采用了极具数学直觉的经典方案：**多项式回归（Polynomial Regression）**。

本文档将深度复盘多项式方案在处理复杂美术规则时遭受的“滑铁卢”，以及剖析为何极简的多层感知机（MLP）能在数学底层实现完美的降维打击。

---

## 1. 传统图形学的直觉：多项式回归

### 1.1 数学模型设定
在早期的尝试中（对应 `fit_polynomial.py`），我们的目标是寻找一个多元数学函数 $f(L\cdot V, L_{up})$。为了捕捉非线性的光照衰减，我们将其展开为高阶多项式，例如：
$Param = W_0 + W_1 X + W_2 Y + W_3 X^2 + W_4 Y^2 + W_5 X Y + W_6 X^3 + \dots$
其中 $X$ 为 $L\cdot V$，$Y$ 为 $L_{up}$，通过最小二乘法等方式拟合权重 $W_i$。

### 1.2 为什么看起来是个好主意？
从图形学底层开发者的角度来看：
1. **指令友好**：在 HLSL 中，计算 $X^3$ 无非就是两个原生乘法指令（`mul`），它极其轻量，不会打破像素着色器（Pixel Shader）的性能预算。
2. **平滑的幻想**：直觉上，二次、三次曲线天生具有极度的平滑性，我们原以为这能带来极为顺滑的光影渐变过渡。

---

## 2. 致命缺陷：多项式在非线性美术逻辑下的彻底破产

当把高阶多项式权重烧录到材质中，并在引擎里旋转光源时，迎来的并非平滑的过渡，而是不可理喻的视觉灾难。这背后的核心原因，是严谨的多项式数学与高度主观的二次元美术逻辑发生了底层冲突。

### 2.1 龙格现象 (Runge's Phenomenon) 与视觉抽搐
我们在几个关键角度（如正面顺光、45度侧光、绝对逆光）采集了完美的美术参数（作为锚点）。多项式为了“绝对穿过”这些离散的锚点，随着阶数的升高，会在区间的边缘或锚点之间产生极其剧烈的数学震荡（这在数值分析中被称为**龙格现象**）。
**灾难表现**：当玩家在顺光和逆光之间缓慢转动视角时，由于底层的曲线正在发生“过山车”般的震荡，角色的面部阴影阈值会突然飙升到极高，瞬间又暴跌至谷底，导致角色在特定角度下出现剧烈的闪烁与疯狂的明暗抽搐。

### 2.2 无限支撑域 (Infinite Support) 与局部失控
这是多项式最大的数学软肋。多项式函数是全局生效的（Global Effect）。
二次元美术逻辑经常存在“突变”的局部规则：例如，“只有当光源退到脑后 120 度时，才强制取消面部阴影，其他时候保持正常”。
如果为了拟合这个“逆光突变”去调整高次项的系数，这一改动不仅影响逆光区域，也会**不可避免地扭曲正面光区域的曲线**。按下葫芦浮起瓢，多项式永远无法做到“只在这个角度发力，在其他角度保持静默”。

### 2.3 性能悖论的反噬
为了压制震荡并勉强拟合这些突变的“局部规则”，我们被迫不断提高多项式的阶数。但当阶数攀升至 5 阶或 6 阶时，HLSL 内部的乘法和加法指令呈指数级膨胀，所谓“性能好”的优势彻底荡然无存。

## 3. 终极解法：MLP（多层感知机）的底层优势

彻底抛弃多项式后，我们重构了基于包含 24 个隐藏节点、单隐藏层 MLP 的架构（`fit_mlp.py`）。这个决定在理论与工程上都取得了压倒性的胜利。

### 3.1 ReLU 激活函数与“分段线性”的数学魔法
MLP 能够成功的最大功臣，是隐藏层中看似极其简单的 **ReLU (Rectified Linear Unit, $f(x) = \max(0, x)$)** 激活函数。
从几何学角度看，单个带有 ReLU 的神经元，就像在三维空间中切了一刀。24 个神经元组合在一起，就构建了一个极其复杂、高度自适应的**高维分段线性函数 (Piecewise Linear Function)**。
**为什么重要？** 这种分段线性结构在连接两个“美术锚点”时，中间的过渡是非常平直、稳定且可预测的。它从数学本质上杜绝了多项式那种“无法抑制的圆滑震荡”，确保了光照在任何角度下过渡得坚如磐石，彻底根绝了视觉闪烁。

### 3.2 局部激活与互不干扰 (Compact-like Support)
得益于 ReLU 函数的截断特性（小于 0 则输出 0），MLP 天然具备类似“局部支撑域”的极品特性。
在训练中，网络会自动分配：让神经元 A 和 B 专门负责拟合“逆光突变”，这俩神经元在正面光照的输入下，输出统统为 0（处于休眠状态）。这意味着，**调整逆光的规则，绝对不会干扰正面光的美术表现**。各个神经元各司其职，完美契合了二次元主观、割裂的美术规则。

### 3.3 极致精简的指令对弈
在获得百倍于高阶多项式的稳定性和精度的同时，其 GPU 性能消耗居然更低！
因为一个 24 神经元的浅层 MLP，在 Shader 中展开后仅仅是几十次原生的 `mad`（乘加 FMA 硬件加速指令）和 `max` 指令。这是一种真正的“性能与效果双赢”的技术跃迁。

---

## 4. 结语

从多项式回归的惨败到 MLP 的惊艳表现，揭示了图形渲染中一个深刻的哲学：**用传统的解析数学硬套高度感性、非线性且突变的主观美术规律，注定会陷入无解的震荡与死结**。只有利用神经网络这种基于数据驱动、具有局部激活与分段线性重构能力的模型，才能实现对现代风格化渲染的降维控制。
